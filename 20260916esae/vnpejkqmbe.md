# “蚊”风丧胆，安心度夏—儿科傅宏娜医生为您支招

> 更新时间：2026-09-16 (UTC+8)

夏天到了，小朋友们娇嫩的皮肤很容易被蚊子亲吻，特别是室外、水边、公园里……起痒痒的包，很痒很难受。为什么会这么痒呢？因为蚊子唾液中的蛋白质是一种过敏原，叮在皮肤上会引起过敏反应。不过只有少数人会发生对蚊子叮咬的过敏反应。

20世纪40年代，科学家首次描述了机体对蚊唾液产生的致敏作用及自然脱敏的过程。免疫球蛋白E(IgE)、免疫球蛋白G(IgG)及淋巴细胞均参与了局部反应的发生。

❂ 蚊子叮咬后，典型的局部皮肤反应有哪些呢？
1. 叮咬后20分钟皮肤出现风团，直径从2厘米至大于10厘米不等，发红、发热、肿胀、瘙痒或硬结，数小时内消失。

2. 在叮咬后24～36小时内发生上述皮肤表现，经8～12小时或更长时间进展，在3～10日内消退。

3. 如果蚊子叮咬到面部，可以使整个眶周区域及面部大部分区域肿胀，尤其常见于婴儿和小儿童。可干扰视物、进食、饮水。严重的叮咬可伴有低热和不适。

4. 蚊子叮咬后的反应主要就是痒，疼痛不明显，这也是和其他昆虫咬伤和螫伤反应的区别。蝇类或其他昆虫咬伤是疼痛性的，蜜蜂、胡蜂、大黄蜂、黄色大胡蜂、白面胡蜂或火蚁的蜇伤也是疼痛性的。

❂ 如何预防蚊子的叮咬呢？
1. 避免过早或过晚外出，避免长时间呆在有水、潮湿、植被茂盛的地方。

2. 外出时给宝宝穿上透气的长袖、长裤，尽量不暴露皮肤。

3. 让宝宝在蚊帐、睡袋中睡觉。杀虫剂扑灭司林适用于纤维织物(如帐篷、睡袋及衣物)，但不可直接用于人皮肤上。

4. 人体的体味、皮肤温度及呼出的二氧化碳可吸引蚊子。含避蚊胺(DEET；N,N-二乙基-3-甲基苯甲酰胺)的产品可以极好地保护宝宝避免蚊虫叮咬。DEET的浓度越高，保护作用越持久。浓度为10%的DEET可安全用于2月龄以上儿童的皮肤。但高浓度的DEET用于有擦伤或晒伤的皮肤或误食误吸后，有潜在的神经毒性。

5. 其他药物，如香茅醛及柠檬桉油，效力较弱且持久性也相对较差。例如，香茅醛的有效时间可能仅持续20分钟，桉树油的有效时间可能仅持续2小时。

❂ 被蚊子叮咬后如何缓解症状和治疗呢？
1. 局部叮咬处涂一些止痒的药物，能让宝宝感觉舒服些，如炉甘石洗剂。

2. 抗组胺药，如西替利嗪（6个月以上婴儿可使用）、氯雷他定（2岁以上儿童可使用）等，减轻过敏反应中的瘙痒，以及皮肤发红、肿胀及硬结。

3. 糖皮质激素 ，中效外用糖皮质激素乳膏（如尤卓尔），可减轻瘙痒、发红、温热及肿胀，一日2次，连用5～10日。口服糖皮质激素（如泼尼松）用于治疗蚊叮咬所致的严重的过敏反应。
